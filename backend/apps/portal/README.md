# Enterprise Parent, Student & Staff Self-Service Portal (EPSSP) Documentation

This document describes the portals profiles, custom shortcuts, target bulletins, activity logs, bookmarks list, and notifications inbox of the **portal** app.

---

## 1. Profiles & Shortcuts
- **PortalProfile**: Maps user settings (theme, timezone).
- **PortalShortcut**: User-customizable action links.

---

## 2. Targeted Announcements
- **PortalAnnouncement**: Targeted bulletin alerts.

---

## 3. Logs & Notifications
- **PortalBookmark**: Custom bookmark links.
- **PortalActivity**: Chronological activities logs.
- **PortalSession**: Devices access tracker.
- **PortalNotification**: Portal mailbox alerts.

---

## 4. REST APIs
Endpoints are mapped under `/portal/api/v1/`:
- `GET/POST /portal/profile/`: Profile configuration.
- `GET/POST /portal/shortcuts/`: Shortcuts customization list.
- `GET/POST /portal/notifications/`: Inbox list.
