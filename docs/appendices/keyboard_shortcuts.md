# Appendix I — UI Keyboard Shortcuts (`docs/appendices/keyboard_shortcuts.md`)

- `Ctrl + Shift + N`: Launch Enterprise Onboarding Wizard (`/hr/admin/onboarding/wizard/`)
- `Ctrl + Shift + P`: Open Payroll Console (`/hr/payroll/`)
- `Ctrl + Shift + A`: Open Attendance Clock-In Terminal
- `Ctrl + Shift + S`: Global Enterprise Search Bar
