# Appendix F — Database Relational Schema Inventory (`docs/appendices/db_inventory.md`)

- `hr_employeeprofile`: Core employee profile aggregate.
- `hr_jobposition`: Headcount management model.
- `hr_compensationhistory`: Effective-dated salary history.
- `hr_contracthistory`: Contract lifecycle history.
- `hr_onboardingdraft`: 8-step wizard auto-save draft model.
- `hr_approvalworkflow`: Dynamic approval workflow configuration model.
- `hr_hrsettings`: SaaS tenant configurations & feature flags.
- `hr_hrauditlog`: Security audit logging table.
